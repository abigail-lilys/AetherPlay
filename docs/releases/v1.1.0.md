## AetherPlay v1.1.0

本版本重点完善 Android 上 WOLF RPG 存档与玩家原始游戏目录之间的持久化链路，并补齐可用于排查问题的运行日志。

### Fixed

- 修复 Android SAF 对 `save` 与 `Save` 的大小写匹配问题，保存时复用已有目录和文件，避免重复生成 `Save (1)`、`Save (2)` 等目录。
- 在 BrowserWoditor 动态创建 `-GameCache` / `-Save` IDBFS 挂载后安装同步钩子，降低保存事件被漏掉的风险。
- 跳过保存过程中的 0 字节临时槽位，避免空内容覆盖有效存档。
- 对外部存档写入进行回读比较；日志记录目标槽位、字节数、SHA-256 和失败原因。

### Added

- 增加从虚拟存档同步到 Android SAF 目录的诊断事件，包括 IDBFS 同步、候选扫描、发布消息和原生写入结果。
- 补充存档系统架构说明与故障排查文档。

### Verified

- `pnpm build` 成功。
- `npx cap sync android` 成功。
- Android 实机日志确认 `SaveData01.sav`、`SaveData02.sav`、`SaveData03.sav`、`SaveData04.sav` 与 `SaveData99.sav` 写入外部目录成功。
- 手动确认保存更新已有 `save` 文件夹，没有继续创建重复文件夹。

### Known scope

当前外部写回桥接针对 `Save/SaveDataNN.sav`。本次记录的设备日志没有单独验证 `SaveData09.sav`，也不应将本功能描述为任意文件同步器。
